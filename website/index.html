152-ФЗ · MCP · CLI · GitHub Action · scan-url

Проверка сайта на риски персональных данных до деплоя

legitAgent читает HTML, JSX и TSX вашего React/Next-проекта и находит типичные дыры: формы без согласия, метрика без opt-in, cookie-баннер, иностранные трекеры, неполная политика. В Cursor, Claude, Kimi — через MCP; в терминале — CLI; в CI — GitHub Action с SARIF и комментарием в PR; живую страницу — командой scan-url. В корне проекта — опциональный legitagent.config.json.

Полный чек-лист 152-ФЗ

В каталоге — 11 правил. Автопоиск в исходниках закрывает формы, политику, метрики, cookie-баннер и иностранные трекеры; живой scan-url ждёт гидрацию SPA, нажимает «отказ», если кнопка есть, и проверяет cookie до и после отказа. Быстрый старт

MCP — для агентов

Cursor, Claude Code, Kimi Code и другие клиенты с MCP:

{
  "mcpServers": {
    "legitagent": {
      "command": "npx",
      "args": ["-y", "@legit-agent/mcp"]
    }
  }
}

Инструменты: scan, scan_url, list_rules, explain_rule

CLI — для терминала и CI

Node.js 20+, без установки:

npx @legit-agent/cli scan
npx @legit-agent/cli scan ./my-site --json --sarif
npx @legit-agent/cli scan-url https://example.com

Код выхода 1 при находках high. В CI — GitHub Action с SARIF и комментарием в PR. Опционально — legitagent.config.json в корне.

Как это работает

  1. 1 Сканер обходит .html, .jsx, .tsx
  2. 2 Сверяет код с YAML-каталогом правил и выдержками статей
  3. 3 Возвращает находки: файл, строка, норма, как исправить
  4. 4 Агент или разработчик принимает решение
