Проверка сайта на риски персональных данных до деплоя

legitAgent читает HTML, JSX и TSX вашего React/Next-проекта и находит типичные дыры: форма без согласия, метрика без opt-in, нет ссылки на политику. В Cursor, Claude, Kimi — через MCP; в терминале и CI — одной командой.

Форма без согласия

PDN.FORM.NO_CONSENT

Email, телефон или имя в форме — но нет чекбокса согласия на обработку ПДн.

high · ст. 9
📊

Метрика без opt-in

PDN.TRACKER.NO_CONSENT

Метрика, gtag, GA, Meta Pixel или VK.Retargeting стартуют сразу, без проверки согласия.

high · ст. 6
🔗

Нет политики

PDN.POLICY.NO_LINK

В проекте не найдена ссылка на политику обработки персональных данных.

high · ст. 18.1

Полный чек-лист 152-ФЗ

В каталоге — 11 правил: cookie-баннер, предзаполненный чекбокс, трансграничная передача, локализация, уведомление РКН и другие. Агент объясняет каждый пункт через list_rules и explain_rule, даже если автопоиск ещё не реализован.

Быстрый старт

MCP — для агентов

Cursor, Claude Code, Kimi Code и другие клиенты с MCP:

{
  "mcpServers": {
    "legitagent": {
      "command": "npx",
      "args": ["-y", "@legit-agent/mcp"]
    }
  }
}

Инструменты: scan, list_rules, explain_rule

CLI — для терминала и CI

Node.js 20+, без установки:

npx @legit-agent/cli scan
npx @legit-agent/cli scan ./my-site --json

Код выхода 1 при находках high

Как это работает

  1. 1 Сканер обходит .html, .jsx, .tsx
  2. 2 Сверяет код с YAML-каталогом правил и выдержками статей
  3. 3 Возвращает находки: файл, строка, норма, как исправить
  4. 4 Агент или разработчик принимает решение
