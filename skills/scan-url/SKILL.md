# Scan URL

1. Вызови MCP-инструмент `scan_url` сервера legitagent.
   - URL — из текста после `/scan-url`. Если URL нет, спроси и не вызывай инструмент без него.
   - Опционально `evidenceDir` для скриншотов.
2. Если доступен MCP `review`, вызови его по findings live-скана (или используй логику review в чате).
3. Покажи findings с `verdict: confirm` и `ask_human`. **`reject` не показывай как нарушение.**
4. Дисклеймер: эвристика, не юридическое заключение. Не выдумывай находки.
