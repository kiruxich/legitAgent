# Fix

1. Вызови MCP `scan` сервера legitagent (без `root`, если путь не указан).
2. Вызови MCP `review` с тем же контекстом.
3. Исправь только находки с `verdict: confirm` по полю `fix`. **`reject` не чини** — это не баг.
4. После правок снова `scan` + `review`. Повторяй, пока не останется `confirm` с `severity: high`, если пользователь явно не принял риск.
5. `ask_human` покажи человеку.
6. Дисклеймер: эвристика, не юридическое заключение.
