# Check

1. Вызови MCP-инструмент `scan` сервера legitagent.
   - Всегда передай абсолютный `root` — корень открытого workspace. Без `root` User MCP сканирует домашний каталог.
   - Если пользователь указал путь после `/check`, используй его.
   - `en` или `--lang en` → `lang: "en"`.
2. Затем вызови MCP `review` с тем же `root` и `lang`.
3. Review работает `offline` по умолчанию и не вызывает внешнюю LLM. OpenRouter или локальная модель используются только если пользователь настроил env режима.
4. Покажи `confirm`, `ask_human` и `not_reviewed` вместе с `kind`, `confidence` и `evidence`. **`reject` не показывай как нарушение** — это отклонённое срабатывание эвристики.
5. Не передавай `write: true` в `autofix` автоматически: этот флаг применяет все safe-рецепты свежего scan, а не только LLM-`confirm`. Покажи safe/manual recipes; изменяй код только после подтверждения соответствующей находки человеком и с достаточным confidence. `ask_human` и `not_reviewed` покажи человеку для решения.
6. После исправлений пересканируй (`scan` + `review`), пока high `confirm` не исчезнут или пользователь явно не примет риск.
7. Напомни: это эвристика, не юридическое заключение. Не выдумывай находки.
