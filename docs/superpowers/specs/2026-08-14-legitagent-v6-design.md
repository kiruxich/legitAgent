# legitAgent — спецификация v6 (тарифы)

Дата: 2026-08-14  
Статус: предложение. Не реализовывать, пока не согласован этот документ.

CLI, MCP, каталог правил и исходники остаются **MIT и бесплатными**. Платное — облачный слой вокруг открытого сканера, не «обрезанный» детектор.

## Почему не paywall исходников

Пакеты `@legit-agent/*` уже на npm. Запереть правила за подписку значит либо сменить лицензию, либо форк-враждебный split. Доверие к compliance-тулу держится на том, что эвристики можно прочитать. Поэтому Free = всё, что работает локально. Pro/Team = хостинг, очередь URL, кабинет, мониторинг.

## Тарифы

Цены ориентир в ₽/мес, без НДС; годовая оплата −20%. Не юридическая услуга ни на одном тарифе.

### Free — «Открытый»

Для кого: разработчик, open-source, CI одного репозитория.

Входит:

- `legitagent scan` по исходникам, все 15 правил
- MCP: `scan`, `list_rules`, `explain_rule`, `get_law`
- `--lang en`, Vue/Svelte/Astro, `legitagent.config.json`
- GitHub Action (SARIF, комментарий PR, issue на high)
- Локальный `scan-url` (свой Playwright)
- `init-policy` / `generate_policy` — черновик, как сейчас
- Каталог и корпус законов в пакете

Лимиты: без кабинета, без облачного обхода URL, без расписания, без командных baseline.

Цена: 0 ₽.

### Pro — «Сайт»

Для кого: студия / ИП / один продакт, которым нужен регулярный проход по уже задеплоенному сайту.

Цена ориентир: **1 490 ₽ / мес** (один оператор, до 3 доменов).

Входит всё из Free, плюс:

- Облачный `scan-url`: не ставить Chromium, API `POST /v1/scans` по URL
- Полный DOM-каталог (как в v5) на проде, не только cookie
- Расписание: ежедневно / еженедельно, письмо при новых `high`
- Baseline: «это уже смотрели, не орём в PR» (облачный `ignoreFindings`)
- История сканов 90 дней
- PDF/Markdown отчёт для заказчика (с дисклеймером)
- Автообновление корпуса законов на стороне сервиса

Не входит: несколько организаций, SSO, общие очереди команды.

### Team — «Студия»

Для кого: агентство или in-house с несколькими сайтами и репозиториями.

Цена ориентир: **4 990 ₽ / мес** (до 10 мест, до 20 доменов / 20 репозиториев). Дальше +990 ₽ за пачку 5 доменов.

Входит всё из Pro, плюс:

- Кабинет организации, роли (owner / member)
- Общий baseline и `disabled` на орг
- Комментарий в PR из облака (GitHub App), не только локальный Action
- Несколько URL за один прогон (карта сайта / список)
- Аудит-лог «кто сканировал / кто замьютил правило»
- Приоритетная очередь Playwright
- Опционально: webhook в Slack/Telegram при high

Не входит: white-label юриста, отраслевые пачки медицина/финансы (это отдельный аддон позже).

### Enterprise — по запросу

On-prem MCP/CLI без изменений (MIT). Доплата только за: выделенный раннер scan-url, договор, счёт, SLA 99.5%, SSO/SAML, хранение в РФ. Не продаём «юридическое заключение».

## Что остаётся бесплатным навсегда

- Каталог YAML и детекторы
- Локальный scan / scan-url / MCP
- GitHub Action как есть в репозитории
- Генератор черновика политики (с дисклеймером)

## Что сознательно не продаём

- «Соответствуете 152-ФЗ» как сертификат
- LLM, который сам ставит finding без детектора, в CI
- Обёртку над SitePravo / 152-audit.ru
- Paywall отдельных rule id

## Технический контур (когда дойдёт до реализации)

1. Сайт: страница `/pricing` + кабинет (email magic link).
2. Биллинг: ЮKassa или CloudPayments (РФ), не Stripe-first.
3. API: ключ `lgt_…`, лимиты по тарифу, Playwright в очереди (Browserless или свой пул).
4. Feature flags в `@legit-agent/cli` не нужны для Free: облако — отдельный пакет `@legit-agent/cloud` или сервис `api.legitagent.ru`.
5. MCP: новый инструмент `scan_url_hosted` только с API-ключом; локальный `scan_url` не трогать.

## Критерий успеха v6

Человек может пользоваться сканером как сейчас без аккаунта. Человек с тремя продакшен-сайтами платит Pro и получает письмо, если после деплоя снова нет политики или формы без согласия.
