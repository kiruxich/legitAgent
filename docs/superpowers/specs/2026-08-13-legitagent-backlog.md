## Сканер живого сайта

- Playwright: открыть уже задеплоенный URL и проверить DOM, куки, баннер, SSL
- Пост-деплой цепочка: push → деплой → проверка продакшена
- Cookie/localStorage с ПДн до согласия (в исходниках это слабо видно)

## CI / GitHub

- GitHub Action `@legitagent/action`
- SARIF-отчёт, комментарий в PR, Issue при high-рисках
- Блокировка билда по `fail-on-high-risk`
- Триггер `deployment_status`

## Больше фронтенд-стеков

- Vue, Svelte, Astro, обычные `.njk` / `.ejs` / `.php` шаблоны
- Кастомные UI-киты форм (не нативный `form`/`input`)
- Более умный поиск «обёртки согласия» вокруг Метрики (не только верхний уровень модуля)

## Закон и каталог

- Полный корпус 152-ФЗ / 38-ФЗ / ЗоЗПП в продукте
- Свой краулер pravo.gov.ru
- Интеграция с law7 как справочником актуальных редакций
- Автообновление выдержек при изменении закона
- 38-ФЗ и ERID-маркировка рекламы
- ЗоЗПП: оферта, реквизиты, возврат, цены
- Отраслевые пачки (медицина, финансы, 18+) — не копировать SitePravo, строить свои правила
- Детекторы для всех `planned` правил из v1-каталога:
  - предзаполненный чекбокс согласия
  - ссылка на политику рядом с формой
  - состав политики (оператор, цели, сроки, отзыв)
  - cookie-баннер с отказом
  - иностранные трекеры / трансграничная передача
  - локализация данных в РФ
  - уведомление РКН и оргмеры — как чек-лист «спросить человека», не как AST

## Продукт и UX

- `legitagent.config.json`: ignore, отключение правил, severity
- `--lang en` и двуязычные сообщения
- Один пакет вместо scope (уже отвергнуто для v1; не возвращаться без причины)
- Обёртки над чужими API (SitePravo, 152-audit.ru) — не делать ядром
- LLM, который сам «видит нарушения» по тексту закона без детектора — только как экспериментальный слой, не как CI
- Конфиг MCP не через npx, а установленный бинарь / Docker
- Генерация текста политики / согласия (юридические документы писать не в v1 и не без юриста)

## Релиз и экосистема

## Зафиксированные решения v1 (чтобы не переоткрывать)

Эти пункты уже согласованы. Менять — только явно, не «заодно».

- Первая поставка: MCP + CLI + каталог + 3 детектора, без Playwright и Action
- Правила — YAML, закон — короткие выдержки статей, не полный корпус
- Скан: JSX/TSX + HTML (React / Next.js)
- Тексты для человека — по-русски, id правил — латиница
- npm-организация `@legitagent`, пакеты `core` / `cli` / `mcp`
- Лицензия MIT
- Архитектура: монорепо pnpm, один мозг `core`, CLI и MCP тонкие оболочки
- Zero-config
- Публичный GitHub + публикация npm (`--access public`)
