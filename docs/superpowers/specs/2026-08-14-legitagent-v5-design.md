# legitAgent — спецификация v5

Дата: 2026-08-14  
Статус: поставлено (v0.5.0). Платного тарифа нет; в v6 облако и тарифы тоже не делали.

v1–v4 остаются в силе: эвристики, не юрзаключение; MCP не пишет патчи; YAML-каталог; MIT; `@legit-agent/*`.

## Цель

Меньше ложных срабатываний на исходниках. Живой `scan-url` проверяет тот же каталог правил по DOM, что и `scan` по файлам.

## Точность

1. `PDN.ORG.RKN_NOTICE` — только если в проекте есть форма с ПДн (`<form>` + `<input>` + email/телефон/имя). Трекер без формы не считается обработкой. Положительный сигнал: `Роскомнадзор`, `pd.rkn`, `реестр операторов`. Серьёзность по умолчанию: `low`.
2. `PDN.LOCALIZATION.UNCLEAR` — иностранный трекер **и** форма с ПДн. Не срабатывает на одном `gtag(` в лендинге без сбора ПДн. Положительный сигнал расширен: территория РФ / России, локализация, хранение в РФ. Серьёзность по умолчанию: `low`.
3. Витрина ЗоЗПП — сильный признак магазина: `addToCart` / `add-to-cart` / `оформить заказ`, либо одновременно «корзин» и «купить». Одно «Купить» в CTA не считается витриной.
4. `PDN.TRACKER.NO_CONSENT` не срабатывает, если в файле виден CMP/обёртка согласия: Cookiebot, tarteaucitron, OneTrust, cookieyes, CookieConsent, cookie-consent, hasMarketingConsent (плюс уже существующий `if (consent)`).
5. Согласие в форме: кроме `type="checkbox"` учитываются `<Checkbox` и `role="checkbox"`.

## Живой DOM

`scanUrl` после загрузки страницы прогоняет те же детекторы исходников по HTML (`scanSources`). Cookie до согласия и клик «отказ» остаются браузерными. Находки дедуплицируются по `ruleId` + `file`. `file` для страничных правил — URL.

Фикстуры live, которые не проверяют политику, содержат ссылку на `/privacy`, чтобы `PDN.POLICY.NO_LINK` не зашумлял существующие тесты.
