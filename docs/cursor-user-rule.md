Перед коммитом или сдачей изменений в HTML/JS/TS/JSX/TSX/Vue/Svelte/Astro, если затронуты форма с ПДн, метрика/трекер или cookie-баннер: вызови MCP `scan` сервера legitagent, затем `review`. Review работает offline по умолчанию; OpenRouter или локальная LLM используются только после пользовательской env-настройки (ключ OpenRouter без явного режима также opt-in). `reject` не чини, `ask_human` и `not_reviewed` покажи человеку. Safe autofix сначала запускай в dry-run: `write: true` применяет все safe-рецепты свежего scan, поэтому запись делай только после проверки preview и явного подтверждения. После исправлений снова вызови `scan` + `review`. Не коммить, пока остаётся `high` с достаточным confidence, если пользователь явно не принял риск. Это эвристика, не юридическое заключение.
